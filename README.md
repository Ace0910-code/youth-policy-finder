# 👀 눈 떠보니 지원 대상이었습니다

**공공데이터 기반 AI 맞춤형 청년정책 추천 서비스** — 광운대학교 제2회 파이썬 SW 활용 경진대회(심화활동) 출품작

내 정보(나이·지역·소득·직업상태·주거·관심분야)를 입력하면, 4종 공공데이터에서 수집한 청년정책 중
**지금 실제로 신청할 수 있는 정책**을 자격 규칙으로 걸러내고, AI 의미 매칭으로 적합도 순위를 매겨 추천합니다.

## 아키텍처 — "그냥 챗봇"이 아닌 하이브리드 매칭

```
┌───────────────────────── 데이터 수집 계층 ─────────────────────────┐
│ 온통청년 API(★핵심)   정부24 serviceList(+supportConditions 조인)  │
│ 복지로 XML(청년 필터)  한국장학재단 학자금지원정보                  │
│          └── demo_realdata.py 병합·중복제거 → policies_real.json   │
│              (키 없으면 직접 작성한 샘플 30건 policies.json 사용)  │
└────────────────────────────────┬──────────────────────────────────┘
                                 ▼
┌───────────────────────── 추천 엔진 (recommender.py) ──────────────┐
│ ① 규칙 기반 자격 필터 (결정론적)                                   │
│    나이·지역·소득·직업상태·주거 + 마감일 판정                      │
│    → 정확성 보장. LLM은 자격 판정에 절대 관여하지 않음(환각 차단)  │
│ ② 의미 기반 관심분야 매칭                                          │
│    ko-sBERT(jhgan/ko-sroberta-multitask) + cosine similarity       │
│    모델 없으면 키워드 규칙 자동 폴백 / 정책·질의 임베딩 캐싱       │
│ ③ 가중 스코어 순위화 → 적합도(%)                                   │
│    신청가능성 0.40 + 관심분야 0.25 + 지원효과 0.15                 │
│    + 마감임박 0.10 + 실행가능성 0.10                               │
│ ④ 설명 생성 (설명 전용): 추천 이유·AI 한줄 요약·체크리스트         │
└────────────────────────────────┬──────────────────────────────────┘
                                 ▼
┌───────────────────────── UI (app.py, Streamlit) ──────────────────┐
│ 입력 화면 → 결과 대시보드 (내 정보 / 스탯·필터·정책카드 / TOP3)   │
│ + 정책 Q&A 챗봇 (chatbot.py): 검색은 ko-sBERT, 답변은 데이터 필드 │
│   템플릿만 사용(환각 차단 일관 적용) · 후속 질문 맥락 기억         │
└───────────────────────────────────────────────────────────────────┘
```

## 실행 방법

```bash
pip install -r streamlit_app/requirements-full.txt   # 로컬 전체 기능(ko-sBERT 포함)
# ※ 루트 requirements.txt는 Streamlit Cloud 배포용 경량 버전(키워드 매칭 폴백)

# 1) 추천 엔진 단독 데모 (키 불필요)
cd streamlit_app
python recommender.py

# 2) 웹 앱 실행 (키 불필요 — 샘플 30건으로 완전 동작)
streamlit run app.py

# 3) 정확도 검증 (페르소나 24명)
python evaluate.py            # → evaluation/정확도_리포트.md

# 4) 수집기 매핑 검증 (키 불필요)
python collect_ontongyouth.py --demo
python collect_gov24.py --demo
python collect_bokjiro.py --demo
python collect_scholarship.py --demo
```

> Streamlit 첫 실행 시 이메일 입력에서 멈추면 `~/.streamlit/credentials.toml`에
> `[general]` / `email = ""` 두 줄을 만들어 두면 됩니다.

### 실데이터 수집 (인증키 필요)

| 키 | 환경변수 | 발급처 |
|---|---|---|
| 온통청년 전용키 | `ONTONG_API_KEY` | youthcenter.go.kr → 오픈API |
| data.go.kr 개인 인증키 (정부24·복지로·장학재단 공용, API별 활용신청 필요) | `ODCLOUD_API_KEY` | data.go.kr |
| 장학재단 API UDDI | `SCHOLARSHIP_UDDI` | data.go.kr 활용신청 상세 페이지 |

```bash
set ONTONG_API_KEY=발급키
set ODCLOUD_API_KEY=발급키
python demo_realdata.py --collect    # 4종 수집 → 병합 → policies_real.json + 콘솔 데모
```

`policies_real.json`이 생기면 앱·엔진이 자동으로 실데이터를 사용하고,
기준일도 샘플(2024.07.01)에서 수집일로 자동 전환됩니다. 키는 코드·깃에 절대 하드코딩하지 않습니다(.gitignore 처리).

## 정확도 검증 결과 (페르소나 24명, 제안서 목표 지표 기준)

정답 라벨은 시스템 랭킹과 독립적으로 부여: ① 실제 자격 충족(필드 직접 대조) ② 마감 유효 ③ 관심분야 해당

| 지표 | 샘플 30건 | 실데이터 3,979건 | 목표(제안서) |
|---|---|---|---|
| **Precision@5 (조정)** | **0.879** | **0.900** | ≥ 0.80 ✅ |
| **Recall@10 (조정)** | **0.962** | **0.850** | ≥ 0.70 ✅ |
| **조건 판정 정확도** | **1.000** | **1.000** | ≥ 0.90 ✅ |
| Hit@5 | 1.000 | 1.000 | - |
| 규칙 필터 미탐 | 0건 | 0건 | 0건 ✅ |

- 가중치는 제안서의 예시값(0.40/0.25/0.15/0.10/0.10)에서 출발해 **페르소나 검증 결과로 조정**
  (관심분야 0.25→0.35, 지원효과 0.15→0.10, 실행가능성 0.10→0.05; 대출·융자 상품은
  '한도≠직접 혜택'이므로 지원효과 점수 상한 적용) — 제안서에 명시한 조정 절차를 그대로 수행.
- 단계 분리 분석: 자격 필터가 정답을 놓친 경우 0건(안전성 확보). 잔여 오차는 전부
  "자격은 충족하나 관심분야 밖인 정책이 Top5에 오른" 랭킹 정렬 문제로, 잘못된 자격 안내 위험은 없음.
- 상세: [정확도_리포트_샘플.md](streamlit_app/evaluation/정확도_리포트_샘플.md) ·
  [정확도_리포트_실데이터.md](streamlit_app/evaluation/정확도_리포트_실데이터.md)

## 파일 구성

```
streamlit_app/
├── app.py                  # Streamlit UI (입력 → 결과 대시보드 → Q&A 챗봇)
├── recommender.py          # 하이브리드 추천 엔진 (단독 실행 가능)
├── chatbot.py              # 정책 Q&A 챗봇 (검색=ko-sBERT, 답변=데이터 필드, 단독 실행 가능)
├── keys.py                 # .env → 환경변수 로더 (python keys.py 로 마스킹 확인)
├── collect_ontongyouth.py  # 온통청년 수집 (--demo 지원)
├── collect_gov24.py        # 정부24 수집 + supportConditions 조인 (--demo)
├── collect_bokjiro.py      # 복지로 XML 수집 (--demo)
├── collect_scholarship.py  # 장학재단 수집 (--demo)
├── demo_realdata.py        # 4종 병합 → policies_real.json + 콘솔 데모
├── evaluate.py             # 페르소나 24명 정확도 검증
├── data/policies.json      # 샘플 정책 30건 (키 없이 완전 동작)
└── evaluation/정확도_리포트.md
```

## 유의사항

- 화면의 "추정 총 지원 규모"는 **금액 산정 가능한 정책 기준 추정치**이며, 직접 지원금만 합산합니다
  (대출 한도·자산형성 만기수령액·창업자금 등 1,500만원 초과 상한은 과대추정 방지를 위해 제외).
- 최종 신청 가능 여부는 **각 기관의 공식 심사 기준**을 따르며, 본 서비스는 공공기관 심사를 대체하지 않는
  **사전 자가진단·정책 탐색 도구**입니다.
- 비영리 프로토타입이며 공공데이터는 각 기관의 이용약관을 따릅니다.
